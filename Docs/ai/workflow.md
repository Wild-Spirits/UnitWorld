# Правила работы ИИ-агента

## Перед изменениями

- Прочитай документ из `Docs/` для затрагиваемой области (таблица в `AGENTS.md`) и [pitfalls.md](pitfalls.md).
- Смотри на соседний код и повторяй его стиль ([../code-style.md](../code-style.md)); не вводи новые паттерны
  (исключения, `std::expected`, glob-ы в CMake, сторонние библиотеки), если об этом не просили.
- Проект в активной разработке: незавершённый код (`TODO`, `WIP`, `Tmp*`) — норма. Не «доделывай» и не удаляй его
  попутно, если задача не об этом.
- В рабочем дереве часто есть незакоммиченные правки пользователя. Не откатывай и не переформатируй чужие изменения.

## Проверка изменений

1. Сборка — единственная автоматическая проверка (тестов нет):

   ```powershell
   cmake --build --preset windows-ninja-msvc-x64-debug
   ```

   Требуется окружение MSVC (Developer PowerShell / `vcvars64.bat`). Если `cl.exe` недоступен или каталог
   `build/windows-ninja-msvc-x64` не сконфигурирован — сообщи об этом пользователю, а не считай сборку успешной.
2. При изменении интерфейса в `Vega/Renderer` пересобирается всё (Vega, плагин, Editor) — проверь, что
   OpenGL-бэкенд тоже компилируется.
3. Запуск `Editor.exe` открывает окно и требует GPU с Vulkan — сам его не запускай для проверки, если пользователь
   не попросил; опиши, что стоит проверить вручную (вьюпорт, панели, лог валидации Vulkan в консоли).
4. Не утверждай, что изменение работает, если оно только скомпилировалось.

## Границы

- Не редактировать и не коммитить: `imgui.ini` (перезаписывается редактором), `Assets/Shaders/**/*.spv`
  (генерируются при запуске), каталоги `build/`, `.vs/`, `.vscode/`.
- Не менять версии зависимостей в `FetchContent_Declare` и не добавлять новые без запроса.
- Не трогать `CMakePresets.json` и глобальные флаги компиляции без запроса.
- Коммиты и пуши — только по явной просьбе. Формат сообщения — см. [../code-style.md](../code-style.md#коммиты).

## Документация

- Если изменение меняет архитектуру, порядок жизненного цикла, сборку или правила — обнови соответствующий файл
  в `Docs/` в том же изменении.
- Общие правила для агентов — в `AGENTS.md` и `Docs/ai/`. `CLAUDE.md` только подключает `AGENTS.md`; не дублируй
  в нём содержимое.

## Общение

- Отвечай на языке пользователя (обычно русский). Код, идентификаторы, комментарии в коде и сообщения коммитов —
  на английском.
- Ссылаясь на код, указывай путь и строку.
